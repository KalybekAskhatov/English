# Журнал ошибок

Файл ведёт команда `/debrief`. Правила:

- строка добавляется только с дословной цитатой из источника;
- существующие строки не переписываются, меняются только «Счётчик» и «Статус»;
- открытых ошибок не больше 10;
- источник: `письмо`, `расшифровка` (ручная) или `голос`; ошибка только из голоса в карточки не идёт;
- статус: `открыта`, `в карточках`, `закрыта`. Закрыта — когда в двух ручных расшифровках подряд форма встретилась не меньше трёх раз и каждый раз верно.
